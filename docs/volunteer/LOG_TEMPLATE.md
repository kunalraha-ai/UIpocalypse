Column notes:

- **Safe copy?** — made a local/test DB copy before running (yes / no / n/a — no DB)
- **Min to 1st report** — from receiving the tarball to the first bug report
- **Findings (H/M/L)** — e.g. `2/3/1` from the report's severity counts
- **Real / false / unsure** — per-finding verdict totals after the volunteer checked each one (e.g. `3 / 1 / 1`)
- **Fix prompts worked?** — pasted into their coding agent and the fix applied: all / some / none / didn't try
- **Pay?** — would they pay (money or a subscription) for this tool as-is
